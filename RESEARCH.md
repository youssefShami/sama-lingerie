# Sama Lingerie — Design & Photography Research

Brand: warm, playful, feminine (not sultry, not luxury) lingerie + pajama + loungewear boutique, Saida (Sidon), Lebanon. Bridal trousseau (jihaz) focus.
Palette: marigold `#FFC466` · white · gold `#C9A24A` · blush `#F6D6DC` · cream `#FFF8EE`. Type: Shrikhand (display) + Montserrat.
Research date: 2026-11-08. All image URLs in Part B were checked with `curl -sI` (HTTP 200 + `image/jpeg`) and visually inspected at thumbnail size.

### A3. Scroll-motion patterns — GSAP ScrollTrigger + Lenis implementation notes

Setup once: `const lenis = new Lenis({ lerp: 0.1 }); lenis.on('scroll', ScrollTrigger.update); gsap.ticker.add(t => lenis.raf(t * 1000)); gsap.ticker.lagSmoothing(0);` Respect `prefers-reduced-motion` by skipping scrubs and leaving only fades.

1. **Scroll-trigger reveals** — `gsap.from('[data-reveal]', { y: 40, opacity: 0, duration: .8, ease: 'power3.out', stagger: .08, scrollTrigger: { trigger: el, start: 'top 85%', once: true } })`; batch with `ScrollTrigger.batch` for grids.
2. **Pinned sections** — `scrollTrigger: { trigger: '.steps', pin: true, start: 'top top', end: '+=300%', scrub: 1 }` with a timeline that swaps step text/images (Aceternity "Sticky Scroll Reveal" clone).
3. **Parallax layers** — give layers `data-speed`; `gsap.to(layer, { yPercent: -20 * speed, ease: 'none', scrollTrigger: { trigger: section, scrub: true, start: 'top bottom', end: 'bottom top' } })`. Keep depth to 2–3 layers (daisy sprites, ribbon, product).
4. **Horizontal scroll gallery** — pin a wrapper and `gsap.to(track, { x: () => -(track.scrollWidth - innerWidth), ease: 'none', scrollTrigger: { pin: true, scrub: 1, end: () => '+=' + track.scrollWidth } })`; call `ScrollTrigger.refresh()` after images load.
5. **Scroll progress indicator** — `gsap.to('.progress', { scaleX: 1, ease: 'none', scrollTrigger: { scrub: .3, start: 0, end: 'max' } })`; style as a thin marigold bar or a daisy that "blooms" (scale 0→1).
6. **Scroll-linked image sequence** — preload N JPEG frames (e.g. robe tying itself, 60–90 frames at 1280px), draw to `<canvas>`, drive `frame` with `scrollTrigger: { scrub: .5 }` and `onUpdate` → `ctx.drawImage`. Use the Spline/Peachweb export as the frame source.
7. **Text mask reveals** — split lines with SplitText (now free in GSAP 3.13) or manual spans in `overflow:hidden` wrappers; `gsap.from(lines, { yPercent: 110, stagger: .06 })`. For Shrikhand headlines add a gold `background-clip: text` gradient animated via `backgroundPositionX`.
8. **Marquees** — duplicate the track and tween `xPercent: -50` with `repeat: -1, ease: 'none'`; tie speed to Lenis velocity (`lenis.on('scroll', e => tl.timeScale(1 + Math.abs(e.velocity)/20))`) and flip direction on scroll-up (RONE uses a static CSS ticker; this is the upgrade).
9. **Magnetic buttons** — on `pointermove` compute offset from centre and `gsap.to(btn, { x: dx*.3, y: dy*.3, duration: .4, ease: 'power3' })`, reset on leave with `elastic.out`. Use on the WhatsApp CTA only.
10. **Image clip-path reveals** — `gsap.fromTo(img, { clipPath: 'inset(0 0 100% 0)' }, { clipPath: 'inset(0 0 0% 0)', duration: 1.1, ease: 'power4.inOut', scrollTrigger: { start: 'top 80%' } })`; use `circle()` or a daisy-shaped `path()` on hero/lookbook images for the playful signature.
11. **Hover product-image swap + tilt** — on card hover crossfade second image (`gsap.to`) and `rotateY` ±6° for depth.
12. **Section colour transitions** — `ScrollTrigger.create({ trigger: sec, start: 'top 50%', onEnter/onEnterBack: () => gsap.to('body', { backgroundColor: sec.dataset.bg }) })` to glide cream → blush → marigold.

### A4. ronestore.com — structure & analysis

**What it is.** RONE STORE (Instagram `ronestore.lb`, WhatsApp +961 71 998 527) is a Lebanese women's pajama/lingerie/gifting shop, i.e. a direct local comparable to Sama. The site runs Shopify on the **"Ritual" theme (Shopify theme store id 3625, schema 3.3.1)** — a Horizon-family theme — with Montserrat as the body/accent font and Chivo as a secondary face. Colour schemes extracted from the CSS variables: blush pink `#EFCCCD` (dominant background), deep brown `#331110` (text), plus accent schemes in burgundy `rgb(104 24 44)`, rose `rgb(122 48 68)`, terracotta `rgb(201 88 76)`, light grey `rgb(226 226 226)` and white. Buttons are square (`--border-radius: 0px`), padding 16/24px, sentence-case labels. English + Arabic language switcher, USD prices ($5–$31), Cash on Delivery + Whish Money, delivery across Lebanon in 2–4 business days, free shipping over $200.

**Section order (home, top → bottom).**
- Announcement/marquee ticker: "Free shipping on orders above $200" · "We accept: Cash on Delivery & Whish Money" · "Delivery across Lebanon in 2-4 business days" (CSS marquee, items duplicated)
- Sticky header: Home · Shop · About Us · FAQ · More; language selector; account; cart drawer ("Your cart is empty" / "Continue shopping" / "Log in"); predictive search panel
- Slideshow hero (autoplay with timeline indicator, arrow controls): "Rone Atelier — Where luxury meets femininity" → CTA **"Discover More"**
- Product list (resource-list grid, ~7 items, $11–$26: e.g. Yellow Ruffle Pajama Short Set $13, Black & White lace silk short set with bra $26) with "Add"/"Choose" quick buttons
- "Shop by collection" collection list: PJ Sets · Moms · Gift Boxes · Lingerie Sets · Mugs · Cozy Slippers
- Featured product block: Feminine Bow Set — "From $31.00 USD"
- "Products" grid + **"SHOP ALL"**: 3 Pcs Floral White Pajama Set / 3 Pcs Floral Yellow Pajama Set ($20 sale, $23 regular), 3pcs Blue Headbands / 3pcs Pink Headbands ($5); many "Sold out"
- Footer: WhatsApp link, Instagram, "Get on the list" newsletter (OK button), payment/delivery notes

**Motion choices.** No GSAP, Lenis, Swiper or Lottie is loaded. Motion is theme-native: (1) the CSS `marquee-ticker`; (2) a `slideshow-component` hero with autoplay timeline and easing controls; (3) Ritual's `animated-element` scroll-reveal class (IntersectionObserver fade/slide-up on blocks); (4) **View Transitions API** hooks (`transition-to-main-product`, `transitionToProduct`) so a product card morphs into the product page; (5) sticky header + `scroll-lock` drawers for cart/search. Transitions are short and system-feeling rather than choreographed.

**Typography feel & what reads as polished.** Montserrat throughout at modest sizes with wide tracking on labels gives a tidy, boutique feel; the blush background with brown text is soft and cohesive, and the marquee + bow-themed featured product add personality. Honest assessment: it is a well-configured stock Shopify theme, not an award-level build — the hero is a plain slideshow, product grids repeat, there is no pinned storytelling, no custom type, and much stock is "Sold out". What makes it *feel* better than average is consistency: one palette, one font, square buttons, a single playful tagline, Arabic/English support and Lebanon-specific trust messaging (COD, Whish, delivery times). **For Sama, keep** the local trust marquee, WhatsApp-first CTA, "Shop by collection" with gift boxes, and bilingual toggle; **exceed it** with Shrikhand display type, scroll-choreographed hero (image-sequence or clip-path reveal), pinned "build your jihaz" section, horizontal lookbook, Lenis smoothing, and marigold/cream colour transitions instead of a flat blush page.
